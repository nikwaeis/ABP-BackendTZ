# ReserveSpace — Сервіс управління та бронювання конференц-залів

Цей проєкт створений під час відбору до компанії ABP. Завдання виконано згідно з технічним завданням (ТЗ) на розробку REST API для управління приміщеннями, бронюваннями та динамічного розрахунку вартості оренди.

---

## 1. Загальний опис та бізнес-задачі

**ReserveSpace API** — модульний бекенд-застосунок для автоматизації сервісу оренди конференц-залів для бізнесу.

### Ключові можливості:
1. **Управління конференц-залами (CRUD):** 
   - Створення залів із зазначенням місткості, базової ставки та списку доступних послуг (проєктор, Wi-Fi, звук тощо).
   - Оновлення інформації про зали та послуги.
   - Безпечне видалення залів (із валідацією активних бронювань).
2. **Пошук доступних залів:**
   - Швидка фільтрація за часовим проміжком та мінімальною кількістю місць.
   - Виключення залів, зайнятих іншими бронюваннями (перевірка перетинів інтервалів).
3. **Бронювання та динамічний розрахунок вартості:**
   - Оформлення бронювання із зазначенням дати, часу, тривалості та обраних послуг.
   - Автоматичний розрахунок вартості залу з урахуванням часових тарифів та знижок.
   - Формування деталізованого чека (`PriceBreakdown`) з розбивкою по годинах.
4. **Звіти та бізнес-аналітика:**
   - Зведений звіт про загальну виручку (зали + послуги).
   - Статистика завантаженості та популярності кожного залу.
   - Рейтинг замовлень додаткових послуг та середній чек.

---

## 2. Логіка ціноутворення та розрахунку оренди

Підсумкова вартість бронювання розраховується за формулою:
$$\text{Загальна вартість (TotalPrice)} = \text{Оренда залу (HallPrice)} + \text{Додаткові послуги (AdditionsPrice)}$$

### Тарифні інтервали для залів:
- **06:00 – 09:00 (Ранкові години):** Знижка **10%** (коефіцієнт $0.90$)
- **09:00 – 18:00 (Стандартні години):** Базова ставка залу (коефіцієнт $1.00$)
- **12:00 – 14:00 (Пікові години):** Націнка **15%** (коефіцієнт $1.15$)
- **18:00 – 23:00 (Вечірні години):** Знижка **20%** (коефіцієнт $0.80$)

> **Важливо:** Якщо бронювання перетинає декілька тарифних періодів (наприклад, з 11:00 до 14:00), сервіс `PricingCalculator` покроково розбиває час на інтервали та точно нараховує відповідний коефіцієнт для кожного часового відрізка.

## 3. Архітектура та технічні рішення

Проєкт побудовано з дотриманням принципів **Clean Code** Роберта Мартіна (Uncle Bob) та **SOLID**:

- **Розділення шарів (Separation of Concerns):**
  - `Controllers/` — прийом HTTP-запитів, валідація вхідних даних (Data Annotations), маршрутизація, відповідні HTTP-статуси (200, 201, 204, 400, 404, 409).
  - `Services/ (Abstractions & Implementations)` — чистий шар бізнес-логіки (`IRoomService`, `IReservationService`, `IPricingCalculator`).
  - `Domain/Entities/` — доменні моделі з XML-документацією.
  - `Data/Configurations/` — явна конфігурація таблиць, зв'язків та обмежень через EF Core Fluent API.
  - `Models/DTOs/` — ізоляція контрактів API від сутностей бази даних.
- **Технологічний стек:**
  - **.NET 10** / C# 13 (ASP.NET Core Web API)
  - **Entity Framework Core 10**
  - **PostgreSQL 16** (Npgsql)
  - **Docker & Docker Compose** (для ізольованого та легкого запуску)
- **Продуктивність та оптимізація:**
  - Складений індекс `(RoomId, StartTime, EndTime)` для швидкого пошуку перетинів за часом.
  - Застосування `.AsNoTracking()` для операцій читання.
- **Фінансова стабільність:**
  - Фіксація цін на момент бронювання (`HallPrice`, `AdditionsPrice`, `TotalPrice`), що гарантує незмінність фінансової історії при зміні тарифів залів у майбутньому.

## 4. Специфікація API

### Конференц-зали (`/api/rooms`)
| Метод | Ендпоінт | Опис |
| :--- | :--- | :--- |
| `GET` | `/api/rooms` | Отримати повний список залів із послугами |
| `GET` | `/api/rooms/{id}` | Детальна інформація про зал за ID |
| `GET` | `/api/rooms/available` | Пошук доступних залів (`startTime`, `endTime`, `capacity`) |
| `POST` | `/api/rooms` | Створити новий конференц-зал із послугами |
| `PUT` | `/api/rooms/{id}` | Оновити інформацію про зал та його послуги |
| `DELETE` | `/api/rooms/{id}` | Видалити зал (захищено від видалення при наявності бронювань) |

### Бронювання (`/api/reservations`)
| Метод | Ендпоінт | Опис |
| :--- | :--- | :--- |
| `POST` | `/api/reservations` | Забронювати зал із вибором послуг та повним розрахунком вартості |
| `GET` | `/api/reservations/{id}` | Отримати деталі бронювання та розрахунок за ID |

### Звіти та аналітика (`/api/reports`)
| Метод | Ендпоінт | Опис |
| :--- | :--- | :--- |
| `GET` | `/api/reports/analytics` | Зведений аналітичний звіт для бізнесу (виручка, завантаженість залів, рейтинг послуг) |

## 5. Початкові дані (Seed Data)

Під час першого запуску застосунок автоматично наповнює базу даних згідно з вимогами ТЗ:
- **Зали:**
  - **Зал A:** місткість 50 осіб, базова вартість 2000 грн/год.
  - **Зал B:** місткість 100 осіб, базова вартість 3500 грн/год.
  - **Зал C:** місткість 30 осіб, базова вартість 1500 грн/год.
- **Послуги (доступні для кожного залу):**
  - **Проєктор:** 500 грн
  - **Wi-Fi:** 300 грн
  - **Звук:** 700 грн

## 6. Інструкція із запуску

```bash
docker compose -f ./docker-compose.dev.yml up --build
```
